# Getting help

Parlora is maintained by one person in their spare time. Support is
best-effort.

## Where to go

| You want to…                     | Go to                                                                     |
| -------------------------------- | ------------------------------------------------------------------------- |
| Report a bug                     | [New issue → Bug](https://github.com/Mvh18/parlora/issues/new/choose)     |
| Propose a feature                | [New issue → Feature](https://github.com/Mvh18/parlora/issues/new/choose) |
| Report a security vulnerability  | Private vulnerability reporting — see [SECURITY.md](SECURITY.md)          |
| Report a Code of Conduct concern | team.parlora@gmail.com — see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)     |
| Ask about commercial licensing   | team.parlora@gmail.com                                                    |

Before opening an issue, search the existing ones; a 👍 reaction on an
existing issue is more useful than a duplicate.

## What to include

- What you tried, what happened and what you expected.
- Your environment: OS, GPU and driver, Docker Desktop version, browser, and
  the Parlora version or commit.
- Logs with personal data removed. Never attach real voice recordings or
  transcripts.
